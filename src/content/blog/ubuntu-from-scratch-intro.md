想自己折腾一台服务器，搭博客、跑脚本、挂机器人，第一件事就是选操作系统。打开任何一家云服务商的镜像列表，排在最前面的几乎永远是 **Ubuntu**。这个系列就从零开始，带你把 Ubuntu 从「听说过」用到「能拿它管服务器」。

这是第一篇：不敲命令，先把几个基础概念搞清楚，免得后面走弯路。

## Ubuntu 是什么

简单说：**Linux 是内核，Ubuntu 是基于这个内核做的一套完整操作系统**。

Linux 内核本身只是管理硬件和进程的核心，光有内核没法用。于是各种「发行版」（Distribution）把内核加上软件包管理器、系统工具、桌面环境打包成能直接装的系统——Ubuntu 就是其中用户最多、资料最全的一个，由 Canonical 公司维护，完全免费。

全球公网服务器里跑的系统，绝大多数是 Linux。原因很现实：免费、稳定、资源占用低、远程管理成熟。Windows Server 按核心数收授权费，而 Ubuntu 一分钱不要。

## 版本号怎么看：认准 LTS

Ubuntu 的版本号是「年份.月份」，比如 24.04 就是 2024 年 4 月发布。每两年出一个 **LTS（Long Term Support，长期支持版）**，维护 5 年，免费安全更新：

| 版本 | 发布时间 | 支持到 | 定位 |
| :--- | :--- | :--- | :--- |
| 22.04 LTS | 2022-04 | 2027 | 上一代 LTS，依然常见 |
| **24.04 LTS** | 2024-04 | 2029 | **当前首选** |
| 25.04 等非 LTS | 每年 4/10 月 | 9 个月 | 尝鲜用，不适合服务器 |

**新手只需要记住一条：服务器装 LTS。** 非 LTS 版本 9 个月就停止更新，到时候要么升级要么裸奔，纯属给自己找事。

## Server 版和 Desktop 版怎么选

Ubuntu 官网能下到好几个版本，新手容易纠结，其实区别就一点：**有没有图形界面**。

- **Desktop（桌面版）**：带 GNOME 图形桌面，像 Windows 一样点点鼠标操作。适合自己笔记本、台式机日常用。
- **Server（服务器版）**：纯命令行，没有桌面。开机只占几百 MB 内存，所有操作通过终端完成。

很多人第一反应是「没图形界面我不会用啊」。恰恰相反——**服务器就该用 Server 版**。图形界面平白吃掉 1-2 GB 内存和一堆 CPU，还增加攻击面。而且服务器大多时候不在手边，你本来就是通过 SSH 远程敲命令管理它，图形界面装了也用不上。

这个系列全部基于 **Ubuntu Server 24.04 LTS**。

## 拿什么机器练手

不用专门买设备，这几条路都行：

- **旧电脑 / 闲置小主机**：最推荐。一台吃灰的笔记本或者几百块的 N100 小主机，就是一台 7×24 小时的真服务器。
- **虚拟机**：用 VMware、VirtualBox 或者 Windows 自带的 Hyper-V 在现有电脑里虚拟一台出来，零成本，玩坏了快照恢复。
- **云 VPS**：腾讯云、阿里云、Vultr 之类的轻量服务器，自带公网 IP，适合做需要对外提供服务的场景。缺点是按月花钱，新手期没必要。

我自己的路径是先在虚拟机上把安装和基础命令练熟，然后装了台小主机放家里跑服务——本系列后面文章的截图和配置，都来自这台真实在跑的机器。
